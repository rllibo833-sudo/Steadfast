# Product definition

Steadfast is a local-first governance CLI and a set of portable agent skills. It helps maintainers detect likely scope expansion, missing verification evidence, and product-code budget overruns.

## First-version boundaries
- One local repository at a time.
- Deterministic checks; no AI API or hosted backend.
- Configurable path allowlist.
- Required evidence file validation.
- Product-code line budget and Markdown/JSON reports.

## Limitations
Static checks cannot prove semantic correctness. Human review and meaningful tests remain necessary.
