# Kits

Tempat untuk kit tambahan yang benar-benar dibutuhkan, seperti aset media yang telah disetujui atau paket aturan yang dapat digunakan ulang.

Jangan menambah kit hanya untuk memperbanyak file. Setiap kit harus punya tujuan jelas, pemilik/lokasi output yang jelas, dan tidak menggantikan kebijakan sumber kebenaran di `.steadfast/policy.json`.

Folder ini bukan sandbox dan tidak otomatis memberi AI izin menulis. Perubahan tetap tunduk pada izin tool, scope-check, review, dan CI.
