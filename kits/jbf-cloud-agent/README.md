# JBF Cloud Agent

Remote JBF agent hosted on Cloudflare Workers. `jbf agent <task>` sends work to this Worker; the phone is the task entry point and owner approval surface. Inference tries Cloudflare Workers AI, OpenRouter Free, Groq Free, Cerebras Free (`zai-glm-4.7`), NVIDIA NIM Free Endpoint (`nvidia/nemotron-3.5-lightning-30b-a3b`), and Gemini Free (`gemini-3.8-flash`) only after the owner enables free-tier data use. Providers that need API keys are disabled until provisioned. No paid model IDs or credit purchases are used.

Cerebras documents its Free tier at $0 with lower rate limits and an 8,192-token context cap. NVIDIA currently labels the Nemotron endpoint Free; availability and limits can change. Google's Gemini Free tier may use prompts to improve Google products, so JBF keeps it opt-in. Review status with `jbf agent providers`; provider-agent status is included in `jbf agent agents` and the dashboard.

JBF has one coordinator plus focused specialists for database, SEO/content, VPS/hosting, account onboarding, ads/analytics, and product algorithms. The coordinator routes a task to matching specialists and scopes connected tools by provider. Specialists share one free inference call per task rather than fanning out into extra model calls. Business research can additionally use Market Scout, Unit Economics Analyst, and Evidence Reviewer with source-backed demand evidence. Inspect the roster with `jbf agent agents`.

The agent supports GitHub, Cloudflare, Supabase (read-only), DigitalOcean, and Meta Ads remote MCP. DigitalOcean's official MCP Router supports browser OAuth and resource tools for Droplets, apps, databases, and networking. Connecting does not buy anything. Reads and explicitly idempotent, non-billable updates on existing resources can run automatically. Resource creation/resizing, deletion, deployment/publication, ad budget/delivery changes, and outbound messages wait for exact owner approval. Meta Ads connection currently depends on Meta's OAuth client support and account rollout; do not assume it is connected. Sensitive input fields are redacted in approval summaries.

Run `jbf agent providers` to see which services are connected. For VPS or database tasks, JBF opens DigitalOcean OAuth in the browser. A known-failed Meta Ads connector is not retried on every task and must be restored before ad analysis can run. DigitalOcean resources are not a free tier, so creating or resizing them requires approval with the displayed cost. Cloudflare remains the no-new-account hosting path. GitHub Actions is temporary compute, not a persistent VPS. Google Ads is not yet connected: Google's official MCP needs a Google Cloud project and OAuth setup and is currently read-only, so JBF must report that blocker instead of pretending it can manage campaigns. Account onboarding uses supported OAuth where available; manual sign-up, identity checks, and terms acceptance stay on the provider's official flow.

Deployment creates a separate Worker named `jbf-cloud-agent` and leaves the existing Steadfast Worker untouched. The workflow supports optional `JBF_CEREBRAS_API_KEY`, `JBF_NVIDIA_API_KEY`, and `JBF_GEMINI_API_KEY` secrets. Gemini additionally requires the Actions variable `JBF_GEMINI_FREE_DATA_APPROVED=true`. Secret values are never logged or committed.

`JBF_REGISTRATION_EMAIL` and `JBF_REGISTRATION_PHONE` are separate owner-authorized secrets. The Worker exposes them to the account-onboarding specialist only for explicit registration tasks, never for outreach; Gemini is excluded from any task containing personal contact details. Registration still requires a provider-supported API flow. If a site requires interactive login, OTP, identity verification, or terms acceptance, JBF stops at that step and reports it for the owner.

Free quotas and model availability can change. If configured free inference providers fail, the task stops without a paid fallback. The deployment workflow runs code-level checks only; it does not call inference models. Gmail, WhatsApp, and SnapDeploy are not in this first cloud release.

The agent compares product opportunities—including game-studio tools, image/video generation, and other SaaS ideas—by verifiable buyer demand and the fastest free route to revenue. It can build through connected GitHub and Cloudflare tools; writes and deployments are held for owner approval. Owner-provided email and WhatsApp contact values are installed as Worker secrets and used only in owner-approved outreach or a specifically approved public listing. Gmail and WhatsApp sending connectors are not connected.
