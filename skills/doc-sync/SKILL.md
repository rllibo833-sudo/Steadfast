# Documentation synchronization
1. Derive supported commands and configuration from implementation, not assumptions.
2. Update only docs affected by the behavior change; avoid duplicate documents.
3. Distinguish implemented, partially implemented and planned capabilities.
4. Never describe a configured line budget as current implementation size.
5. Run steadfast docs-check and relevant examples after edits.
